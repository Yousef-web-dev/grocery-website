# 🛒 grocery - Modern E-Commerce Grocery Application

Grocify is a fast, responsive, and interactive online grocery store web application. Designed with a modern UI/UX, it offers a seamless shopping experience complete with product categorization, full shopping cart functionality, wishlist management, and dynamic navigation.

---

## ✨ Key Features

* 🛍️ **Product Catalog & Filtering:** Browse groceries easily filtered by categories (Fruits, Vegetables, Dairy, Seafood, etc.).
* 🛒 **Dynamic Shopping Cart:** Real-time order calculation, item quantity adjustment, and item removal.
* ❤️ **Wishlist System:** Save favorite products and track them seamlessly across the app.
* ⚡ **Animations & Interactions:** Smooth micro-interactions and transitions powered by Framer Motion.
* 📱 **Fully Responsive Layout:** Dynamic navigation bar with an interactive mobile drawer menu.
* 🧭 **SPA Routing:** Instant page transitions without reload using React Router DOM.

---

## 🛠️ Tech Stack & Dependencies

* **Core Framework:** React (Vite)
* **Styling & Layout:** Tailwind CSS
* **Routing:** React Router DOM (`v6+`)
* **State Management:** React Context API (`CartContext`)
* **Animations:** Framer Motion
* **Iconography:** React Icons (`react-icons`)
* **Smooth Scrolling:** Lenis Scroll
